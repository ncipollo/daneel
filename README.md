# daneel

A slow, careful agent built for small, local models.

Named after R. Daneel Olivaw, Asimov's robot who patiently guided humanity for twenty thousand years. Daneel trades speed for care: it iterates in small, deliberate steps so that modest local models can still get the job done.

## Install

```sh
cargo install daneel
```

## Usage

```sh
daneel --help
```

## Development

```sh
cargo fmt
cargo test
cargo clippy
```

Releases are cut with [sheepit](https://github.com/ncipollo/sheepit).
